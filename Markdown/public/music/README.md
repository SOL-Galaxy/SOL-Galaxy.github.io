# 音乐文件夹

这个文件夹用于存放网站音乐播放器的音频文件。

## 使用方法

1. 将你的音乐文件（.mp3, .wav, .ogg 等格式）放到这个文件夹中
2. 在浏览器中配置播放列表，或者修改 `Config/.vitepress/theme/useMusicPlayer.ts` 文件
3. 详细使用说明请查看项目根目录的 `MUSIC-PLAYER-GUIDE.md`

## 示例文件结构

```
music/
├── README.md (本文件)
├── song1.mp3
├── song2.mp3
└── song3.mp3
```

## 注意事项

- 推荐使用 MP3 格式（浏览器兼容性最好）
- 建议文件名使用英文和数字，避免使用特殊字符
- 注意版权问题，仅上传你有权使用的音乐文件
- 较大的音频文件可能影响网站加载速度，建议压缩后使用
